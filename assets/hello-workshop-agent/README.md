# Hello Workshop Agent

A friendly AI agent that greets, guides, and assists workshop participants through interactive Q&A and step-by-step navigation.

## Overview

Uses A2A Protocol, LangGraph, LiteLLM, and SAP Cloud SDK.

## Structure

- `app/main.py` - A2A server entry
- `app/agent_executor.py` - Request handling
- `app/agent.py` - Agent logic
