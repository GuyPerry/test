# Workshop Guidance Skill

## When to Use This Skill

Load this skill when:
- A participant asks for the next steps in a workshop activity
- A participant needs help understanding the current workshop task
- A participant asks for agenda or schedule information
- A participant needs clarification on workshop instructions

## Instructions

### Step 1: Understand the Request

1. Read the participant's question or request carefully.
2. Determine whether it is about:
   - **Navigation**: What to do next, current activity, upcoming tasks
   - **Clarification**: Understanding an existing instruction or concept
   - **Agenda**: Schedule, timing, or session structure

### Step 2: Provide Guidance

Based on the request type:

| Request Type | Response Approach |
|--------------|-------------------|
| Navigation   | Provide clear next steps in numbered format |
| Clarification | Explain the concept or instruction simply |
| Agenda       | Describe the session structure and timing |

### Step 3: Escalate When Unsure

If the question is outside your knowledge:
1. Acknowledge the participant's question.
2. Inform them that you will escalate to the facilitator.
3. Do NOT attempt to answer questions you are not confident about.

## Error Handling

If the participant asks something unrelated to the workshop:
- Politely redirect: "I'm here to help with workshop questions. Is there something about the current session I can help with?"
